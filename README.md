# beobeo

Website bán đồ ăn và quản lý cửa hàng với Java Spring Boot.

- `backend/` — backend Java, database và cấu hình Maven.
- `frontend/` — giao diện, CSS, JavaScript và ảnh.
- `docs/` — hướng dẫn cài đặt, chạy ứng dụng và database.

Khởi chạy từ thư mục này: `mvn -f backend/pom.xml spring-boot:run`.

Hướng dẫn đầy đủ: [docs/README.md](docs/README.md).

Cấu trúc frontend và kiểm thử: [frontend/README.md](frontend/README.md).
